## Contexto del proyecto

App Android para gestionar una quiniela privada entre un grupo. Los usuarios predicen resultados de partidos. Un admin carga partidos desde una API externa, actualiza resultados y el sistema computa puntos automáticamente.

**Arquitectura:** Clean Architecture — Presentation → Domain → Data
- UI: Jetpack Compose + Material 3
- Estado: ViewModel + StateFlow + Hilt
- Async: Kotlin Coroutines
- Persistencia: Firestore con `onSnapshot` (Flow, tiempo real)
- Auth: Firebase Auth (email/Google)
- DI: Hilt

**Decisiones clave:**
- Rol admin via `esAdmin: Boolean` en Firestore `/usuarios/{uid}`, verificado por Security Rules
- Sin datos hardcodeados: el admin puebla todo desde la app
- Bloqueo de predicciones: función pura `calcularEstadoPrediccion()` en capa Domain
- Leaderboard denormalizado en `/leaderboard/general` para lectura O(1)
- Sistema arranca vacío: Admin → Sincronizar desde API → partidos en Firestore → usuarios predicen
